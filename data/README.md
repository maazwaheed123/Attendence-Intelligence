# Sample data (100% synthetic)

Generated by `python -m scripts.generate_data` from [`scripts/seed_spec.yaml`](../scripts/seed_spec.yaml).
Companies, people, phone numbers (555-01xx) and national IDs are fictional.

**How it works:** the generator first builds the *ground truth* (canonical records),
then renders that truth into every file format. Because every file comes from known
truth, every test and demo question has an exact expected answer
(`ground_truth/expected_results.json`).

## Ground truth (`ground_truth/`)

- `ground_truth.json`: canonical truth rows + roster (with fictional PII) and each fact's `evidence_status`
- `manifests.json`: for every file, the exact locator of each row (`row=5`, `sheet=...;row=7`, `page=2;table=1;row=4`, ...), what it says, and whether review is expected
- `expected_results.json`: per test persona, the permitted records, per-date status lists, attendance % by employee/department/week and highest/lowest

### Evidence status
- `clean`: counted in answers and aggregates
- `review_only`: only ambiguous OCR supports it (Lucas, 30 Sep) -> excluded, flagged for review
- `conflict`: sources disagree (Bob, 15 Sep) -> excluded, "needs review" with both citations

### Metric rules
- scheduled day = not a holiday (23 Sep is a holiday)
- present value = 1 for present/WFH, 0.5 for half day, 0 otherwise (leave counts as scheduled, not present)
- attendance % = 100 x sum(present value) / scheduled days, pooled over employee-days

## Optional: a real handwritten photo
Handwrite a short sheet on paper using the **fictional** names above, photograph it, save it as
`generated/real_handwritten_photo.jpg`, and write its truth in `ground_truth/real_photo_truth.json`.
Real handwriting makes the OCR demo much more convincing. Never use real people's data.
